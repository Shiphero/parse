INTRODUCTION
Welcome to Nordstrom’s Manhattan TMS training guide prepared for our vendor and supplier partners. 
The legacy application, Cloud TMS, will no longer be supported in 2026 and can no longer be a part of the shipping solution. 
With Manhattan TMS’ implementation, Nordstrom is taking the opportunity to improve upon old workflows, to minimize 
manual tasks and to create better order visibility. 3
Nordstrom will now use Manhattan Active Transportation Management (or MATM) as its transportation management system 
(TMS) to plan, execute, and optimize the physical movement of goods, and to ensure shipments are compliant with proper 
documentation available. MATM is used by Nordstrom Transportation Operations, Vendors, Carriers and 3rd Party Logistics 
providers. 
CHANGES FROM PREVIOUS WORKFLOWS
Vendors will primarily see changes in the routing request process that will be less manual and will be contained primarily in 
the Manhattan TMS platform (versus NOVS or Outlook).
KEY POINTS
Vendors will no longer need to use the manual request forms to email our Transportation Planner and Consolidators for 
routing requests. Vendors only need to submit their routing request in MATM and don’t need to separate their request 
between consolidator and DC shipments. Previously, you had to send requests separately depending on what instructions the 
Nordstrom Routing Guide dictates. The Nordstrom Routing Guide will be replaced by the Nordstrom Shipping Guide.4
NEW WORKFLOWS
Vendor workflows now leverage the TMS to provide greater visibility as the order moves through the lifecycle.

CONCEPTS AND DEFINITIONS
This section covers terms and concepts that Vendors should become more familiar with as they process shipments.
FACILITIES
Facilities define the Origin Ship-From and Destination Ship-To of an Order. Nordstrom will be importing facilities and updating 
them via integration from their host system. Mismatched facility types and planning types could prevent transportation order 
creation.
Nordstrom will be utilizing 3 facility types:
1. Stores will be used to represent Nordstrom Stores 
2. Distribution Centers will be used to represent Nordstrom Warehouses and Consolidators (Receiving)
3. Vendors will be used to represent Vendor Ship From Locations, 3PL’s and Consolidators (Shipping)
Users should not create or update facilities directly in the UI but rather use them as references only.
SHIPMENT PLANNING
The term “Shipment Planning” refers to the process of moving an order (called a TO at this stage) through optimization (based 
on criteria like weight and count) so it can get assigned to a resource for next steps.23
SHIPMENT STATUSES
Within the TMS, there are different statuses that identify what state a tender, broadcast, transit or stop is for a shipment within 
the system.
Status Definition
Not Started Order has not been planned on a shipment
Planned Order is routed (exists on a shipment)
Partially Planned At least one leg is planned but one or more legs of 
an order are still unplanned.
Unplanned Order has been unplanned from a shipment
SUPPLIER PURCHASE ORDER (SPO)
A Supplier Purchase Order is the name given an order before the routing request (after routing it becomes a Transportation 
Order (or TO).
TENDERING24
TRACK AND TRACE
Tracking is a function beginning after a carrier has been tendered a shipment to notify the shipper of the progress of the freight 
from its origin to its destination. 
Tracking records incoming messages from the carrier and allows the shipper to monitor whether the shipment and its 
supporting orders are on time to handle exceptions to the normal flow. 
› Tracking messages transition the shipment transit status based on transit status rules.
› A shipment will transition from Not Started to In Transit once the carriers sends a Departure tracking message from 
the first stop.
› A shipment will transition from In Transit to Completed once the carrier sends an Arrival or Departure tracking 
message from the final stop.
› Tracking messages can be viewed from the Tracking Messages screen
› Carriers may send the following 214 tracking message types:
− ETAs
− Arrivals
− Departures
− Check Calls

This section covers the basics of using the ULC.
UNIFIED LOGISTICS CONTROL (ULC) BASICS
The ULC serves as a central dashboard view.
MAIN FUNCTIONS OF THE ULC
1. It provides an overview of real-time order and shipment status (like a control tower), giving users visibility into 
transportation performance with early warning alerts and other actionable insights.
2. It enables users to take immediate action (like a command center): The user can respond in real time to trends and 
problems with orders and/or shipments directly from the ULC.
TASKS THAT CAN BE PERFORMED IN THE ULC
❖ Add or remove orders from shipments
❖ Find existing shipments to match an unplanned order
❖ Unplan or combine shipments
❖ View real-time shipment status
❖ Manage carrier tenders
❖ Re-sequence stops
❖ Map orders and/or shipments27

FAQS
This section covers several Frequently Asked Questions with answers.
WHEN DO WE NEED TO SUBMIT A ROUTING REQUEST TO BE CONSIDERED FOR NEXT DAY PICK -UP?
Submit request by 12pm local standard time to be considered for next day pick up. Routing requests submitted after 12pm 
local time will be planned for the following business day.
WHAT DOES NORDSTROM RECOMMEND FOR BOL FORM?
Nordstrom recommends vendors use the MATM provided BOL for shipping because it includes all the required information.
If you use your own BOL, you must include required data on the BOL.
WHAT IS REQUIRED DATA THAT MUST BE ON A BOL?
Must include:
1. MATM Shipment number must be used
2. PO numbers
3. Accurate carton count34
4. Accurate weight
5. Accurate Origin and destination
WHEN SUBMITTING SHIPMENT REQUESTS, DO I NEED TO INDICATE THE DESTINATIONS?
No. MATM should take away the guess work that vendors have when submitting their shipment request and determining the 
destination of their request should go. The POs that vendors receive and import into MATM should indicate the destination. If 
it is shipping direct to DC, direct to Store or NEJ, the PO should indicate that. 
The vendor will only need to provide the shipment details for all the POs going to the same destination on their request.
